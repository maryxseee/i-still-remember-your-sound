# Characters and visible actions Implementation Plan

**Goal:** Виконати запит користувачки: згенерувати головну героїню та трьох персонажів і додати видимі наслідки ігрових дій, особливо очищення й обертання платівки.
**Design:** Залишаємо мальовані кімнати й великий текст. Прозорі повноростові персонажі стоять поверх фону; активний співрозмовник виділений. Крупний план пристрою складається з незалежних рухомих SVG/CSS-шарів. Зображення персонажів — ImageGen, механічні шари — кодова векторна графіка, бо їхній рух залежить від стану гри.
**Heroine:** Доросла студентка, золотаві біляві кучері, карі очі, веснянки, беггі-джинси, відкрита зіпка, топ. Інші герої на розсуд виконавця, одяг відповідної епохи.
**Scope:** Локальна реалізація; зданий сценарій, музика й правила фіналів не змінюються. Публічне завантаження нових матеріалів вимагає окремого дозволу згідно з попередніми автоматичними відмовами для нових версій.
