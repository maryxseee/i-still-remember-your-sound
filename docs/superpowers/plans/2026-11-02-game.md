# I still remember your sound Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Побудувати прохідну локальну версію всіх розділів із збереженням та основою мультимедіа.

**Architecture:** Незалежна модель стану як browser/CommonJS script, декларативний сюжет, DOM-інтерфейс і окремий звуковий модуль. Звичайні локальні script/src і image/src дозволяють запуск index.html без мережі та збірки.

**Tech Stack:** HTML, CSS, JavaScript, Node built-in test runner; ImageGen для фону.

**Spec:** ../specs/2026-11-02-game-design.md

## Global Constraints
- Українська мова; єдина учасниця; не редагувати зданий сценарій.
- Три послідовні розділи й три незалежно вибрані фінали.
- Популярна музика епох не замінюється спільною оригінальною мелодією.
- Локальні ресурси, відсутність мережевих залежностей під час гри.
- Помилки дозволяють повторну спробу, текстові підказки достатні без звуку.

## Review Focus
- Пошкоджене збереження не ламає запуск, недоступне сховище має чесне повідомлення.
- Неправильна дія в головоломці не відкриває наступний розділ і не блокує повтор.
- Нове проходження не стирає раніше відкриті фінали.
- Скасування діалогу повертає клавіатурний фокус; телефонний екран не обрізає дії.
- Відсутній музичний файл не блокує історію й не видається за готову музику.
