# Interaction windows, emotions and stage transitions

**User request:** Прибрати предмети, що висять перед грою та після неї; показувати речі у вікні взаємодії. Дві додаткові емоції героїні: сумна після помилки, радісна після успіху. Активний співрозмовник наближається та підсвічується. Між етапами — коротке відчуття запаморочення.

**Design:** Окремий native dialog для огляду/головоломки, незалежний від налаштувань. Після розв’язання в ньому короткий успішний результат із кнопкою повернення; після закриття предмет зникає повністю. Незавершену гру можна закрити й відкрити з того самого кроку. Сцена показує фон і персонажів, без намальованих поверх неї коробок, платівок або CD. Згенеровані варіанти обличчя зберігають первинну зовнішність. Перехід спотворює тільки зображення кімнати, не читабельний текст; без спалахів, у reduced motion — лише коротка зміна прозорості.
