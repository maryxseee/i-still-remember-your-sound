# I still remember your sound — погоджений напрям

Погоджено користувачкою в чаті 02.11.2026. Єдина учасниця, українська мова, термін 23.11.2026.

## Мета
Мальована інтерактивна браузерна історія на 10–15 хвилин про носії музики, середовище слухання й пам’ять. Пролог, три послідовні епохи, три фінали. Джерело: актуальний зданий сценарій у Downloads, прочитаний без змін 02.11.2026. У сценарії є одна залишкова згадка іншого імені: у грі послідовно використовуємо погоджене Джоні; вихідний документ не редагуємо.

## Підхід і альтернативи
Рекомендовано й погоджено HTML/CSS/JavaScript: сцени, дослідження предметів, діалоги, головоломки. Godot розглянуто як альтернативу для складнішої анімації, але це не потрібно для погодженого формату. Без залежності від CDN, облікових записів і мережі під час проходження. Окрема локальна копія запускається через index.html; додатково є локальний сервер Node для перевірки.

## Історія
Пролог: телефон без завантажених пісень, навушники, коробка, записка про сторону А.
Вініл: огляд, підготовка за краї/очищення/розміщення/швидкість 33⅓/запуск; Ребекка; вибір цілої сторони або особливої пісні; умовна втрата й повернення.
Касета: Джоні, записка й три фрагменти дорога → зустріч → невисловлене. Текстові описи достатні без звуку. Переміщення кнопками й перетягуванням. Вибір зберегти лист або передати копію добірки, залишивши лист адресатові; втрата й повернення.
CD: Анжела, інший альбом, MP3-диск і Audio CD; потрібний запис працює як Audio CD + старий програвач або MP3 + комп’ютер. Вибір спочатку резервної копії або каталогу; втрата й повернення.
Фінальний вибір визначає «Музика вдома», «Музика між нами», «Музика далі». Попередні рішення змінюють текст, без моральних балів. Фінали накопичуються, перезапуск їх не стирає.

## Матеріали
4 мальовані фони: прохолодна сучасна кімната, бурштинові 1970-ті, синьо-рожеві 1990-ті, сріблясто-блакитні 2000-ті. Ілюстрації створюємо ImageGen, написи окремо. Згодом портрети й предмети. Прості механічні ефекти синтезуємо, не видаючи їх за музику епохи. Популярні композиції — окремий список кандидатів; файли не включаються без визначеного джерела й умов. Реєстр матеріалів і титри точно відрізняють використане від запланованого.

## Інтерфейс і доступність
Почати, Продовжити, Відкриті фінали, Про проєкт. Сцена, коротка репліка, дії й щоденник. Регулятори музики й ефектів, вимкнення звуку, зменшення руху, читабельність. Клавіатура, видимий фокус, закриття діалогів Escape, текстові альтернативи. Жодна помилка головоломки не блокує гру. Збереження після дій, обробка пошкодженого/недоступного сховища, ручний експорт/імпорт для автономного запуску.

Інструкція запуску, реєстр матеріалів, текст виступу й відповіді. Презентація та запис проходження після перевірки візуалу й фінальних аудіоматеріалів.
