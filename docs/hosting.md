# Хостинг гри

Основна незалежна публікація: https://maryxseee.github.io/i-still-remember-your-sound/

Додаткова хмарна адреса: https://i-still-remember-your-sound.dustycricket.chatgpt.site

Обидві публікації розміщені поза ноутбуком авторки. Для відвідувачів не потрібні локальний сервер, запущений Node.js, тунель чи вхід у GitHub. GitHub Pages використовується для статичних файлів публічного репозиторію; платного серверного тарифу цей проєкт не потребує. Це не локальна адреса 127.0.0.1.

## Автоматична публікація

Файл `.github/workflows/web-game.yml`: перевірки Node.js22 → `npm test` → `npm run build:web` → завантаження `dist/` → GitHub Pages. Публікація виконується з main; перевірки також працюють у feat/interactive-story та pull requests. Залежностей для встановлення немає.

У налаштуваннях репозиторію Pages має джерело GitHub Actions. Зміни коду й ресурсів зберігаються у звичайному Git. Готова папка dist, тимчасові файли та облікові дані до репозиторію не додаються.

## Що зберігається локально

Прогрес, налаштування й введений особистий спогад залишаються у браузері гравчині. Різні адреси сайтів мають окремі збереження; для перенесення є імпорт/експорт у налаштуваннях. Звук запускається після першого натискання згідно з правилами браузера. Музичні MP3 зберігаються разом із грою.

Офіційна документація: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
