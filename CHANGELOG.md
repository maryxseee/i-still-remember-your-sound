# Зміни

## 1.3.0 · 2026-11-14

- Погоджений 10-секундний мальований MP4-вступ зі зникненням з’єднання й обривом музики.
- Пропуск, керування відео, пауза у фоновій вкладці та відновлення після блокування звуку; продовження збереження не повторює вступ.
- Фонова музика починається після відео, без накладання; вступні репліки узгоджено з коробкою на столі.
- Чотири додаткові перевірки передавання керування, блокування, фонової паузи та помилки відео.

## 1.2.0 · 2026-11-12

- Вбудовані 11 погоджених ілюстрацій: три фотокартки з правильним складом персонажів, чотири плани для огляду та чотири паперові основи.
- Огляд коробки й столів із клікабельними предметами та доступними текстовими кнопками.
- Темний читабельний текст на записках, сторінках і світлих кнопках; окремі стилі для телефона.
- Знаки питання обмежені вступами; портрет Меліси показується і після касетного епізоду.
- Автоматичні перевірки й публікація на GitHub Pages; актуальна документація хостингу.
